ILYSHOOT
========
1. Unzip this folder.
2. Double-click index.html (opens in Chrome, Edge, Firefox or Safari).
No install or internet needed. The game runs offline; the custom fonts load only when online.

CONTROLS
Move: Arrow keys or A / D
Jump: Space or W (hold for a higher jump)
Fire: F, J, K or left-click
Restart level: R
Phone/tablet: on-screen buttons appear automatically.
